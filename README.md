# Full Stack E-Commerce Platform

A full-stack e-commerce web application built using the MERN stack with authentication, product browsing, cart management, and order handling.

## Tech Stack
- **Frontend:** React.js, Tailwind CSS, Redux Toolkit, Vite
- **Backend:** Node.js, Express.js, MongoDB
- **Authentication:** JWT, Email OTP Verification

## Key Features
- User registration, login, and secure email verification
- Product catalog and category-wise browsing
- Shopping cart and checkout system
- User profile and order history tracking
- Admin dashboard for product and order management
